INSTALLATEUR RTMS 2.4.0 EN 4 MORCEAUX

1. Telechargez les 5 fichiers dans le MEME dossier (par exemple Telechargements) :
   RTMS-Setup-2.4.0.exe.part0
   RTMS-Setup-2.4.0.exe.part1
   RTMS-Setup-2.4.0.exe.part2
   RTMS-Setup-2.4.0.exe.part3
   RASSEMBLER.bat
2. Double-cliquez sur RASSEMBLER.bat.
   Si Windows affiche « Windows a protege votre ordinateur » : Informations complementaires > Executer quand meme.
3. Le fichier RTMS-Setup-2.4.0.exe apparait dans le dossier, verifie (empreinte SHA-256).
   Double-cliquez dessus pour installer RTMS.
