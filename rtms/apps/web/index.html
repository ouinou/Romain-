RTMS — connexion sécurisée

Première utilisation sur le poste principal : créez la société et le compte de l’administrateur. Ce compte gérera ensuite les autres utilisateurs.

Le poste principal n’est pas encore installé. Terminez l’installation sur le poste principal, puis rechargez cette page.

Demandez à l’administrateur de RTMS un code de réinitialisation (Administration › Utilisateurs). Il est valable 30 minutes et ne sert qu’une fois.

Première connexion : remplacez le mot de passe provisoire donné par l’administrateur par un mot de passe que vous seul connaissez.

Votre profil impose la vérification en deux étapes. Scannez ce code avec une application d’authentification (Google Authenticator, Microsoft Authenticator, FreeOTP…), puis saisissez le code affiché.
