Logiciel de gestion comptable et financière pour PME et organisations de l'espace OHADA (Cameroun en premier lieu), fonctionnant sur réseau local sans Internet obligatoire.

| `docs/` | Architecture, sécurité, installation Windows, API, feuille de route |
| `index.html` | Maquette d'interface v0.5 : démonstration visuelle uniquement, **pas une application sécurisée** |
| `original-v0.4.html`, `ANALYSE.md` | Maquette d'origine et analyse des corrections |
