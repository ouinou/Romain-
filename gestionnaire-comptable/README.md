# GESTIONNAIRE COMPTABLE

Logiciel de gestion comptable et financière pour PME et organisations de l'espace OHADA (Cameroun en premier lieu), fonctionnant sur réseau local sans Internet obligatoire.

| Dossier | Contenu |
|---|---|
| `serveur/` | API sécurisée, base PostgreSQL, outils d'exploitation, tests |
| `interface/` | Interface web reliée au serveur (React), parcours de test dans le navigateur, version de démonstration |
| `docs/` | Guide d'utilisation, examen de l'existant et choix techniques (ETAPES-1-ET-2), architecture, sécurité, installation Windows, API, feuille de route |
| `index.html` | Ancienne maquette v0.5 : démonstration visuelle uniquement, **pas une application sécurisée**. Elle sera remplacée par `interface/` une fois celle-ci validée. |
| `original-v0.4.html`, `ANALYSE.md` | Maquette d'origine et analyse des corrections |
